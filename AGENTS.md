# Продолжение проекта

Сначала прочитайте `NEW_CHAT_CONTEXT.md` и `START_HERE_RU.md`. Тема, план и текущий этап записаны там; исторические заметки в `materials/` могут содержать устаревшие статусы.

- Сохраняйте полный утверждённый пользователем план. Сейчас написано до 2.2 включительно.
- Текущий исходник для сборки: `research/manuscript.json`; итоговый документ: `docs/Working_Draft_Zhurilov_RoRo.docx`.
- Перед продолжением проверяйте, не редактировал ли пользователь Word вручную после последней сборки. При расхождении согласуйте исходник с правками, прежде чем пересобирать.
- Проверяйте факты по первоисточникам; сохраняйте номера страниц/пунктов и границы применимости. Не выдумывайте данные, источники, расчёты или результаты проверок.
- Пользователь просит экономить лимит: небольшие этапы, без субагентов, если отдельно не попросит.
- Материалы `materials/` предназначены для локальной работы; они исключены из Git. Полные чужие источники и пользовательский диплом-образец не публикуйте.
- ARS сохранён в `materials/research/ars-skill/` полного архива. Читайте применимые инструкции, не заявляйте выполнение непройденных проверок.
- Локальная работа и сборка не требуют Codex Cloud. Публикация через GitHub — отдельное действие, выполняемое по запросу пользователя.
