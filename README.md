# ВКР: остойчивость судов Ro-Ro

Журилов Максим Максимович, С-612. Специальность 26.05.05 «Судовождение», специалитет.

Тема: «Исследование и анализ потери остойчивости судами типа Ro-Ro и пути их предотвращения».

Актуальная версия плана: 2, 9 октября 2026 года. Четыре главы, 19 подразделов. Это предварительный план для обсуждения; главы диплома пока не написаны. Расследования трёх аварий выбраны предварительно и требуют проверки первоисточников.
